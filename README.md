🤖 About This Project

This is my first project of this kind, and it is still a work in progress.

The development of this project was strongly supported by AI-assisted programming tools. AI was used extensively to help with code generation, debugging, refactoring, problem solving, documentation, and integration between different technologies.

However, the project was developed with human direction and management. The ideas, goals, decisions, testing, experimentation, configuration, and final integration were guided and supervised by a human developer.

I am sharing this project not because it is perfect, but because I want to learn, improve it, and make it useful to other people who are interested in local AI assistants, Live2D, voice interaction, and AI-assisted development.

🚧 Work in Progress

As my first project of this kind, the code may still contain areas that could be improved, reorganized, optimized, or rewritten.

There may also be:

Performance issues.
Unoptimized code.
Bugs and unexpected behavior.
Experimental implementations.
Areas that need better architecture.
Features that could be implemented more efficiently.
Documentation that could be improved.

I consider these limitations part of the project's current development stage.

❤️ Final Thoughts

This project started as a personal experiment to explore what could be achieved by combining local AI, voice interaction, computer vision, and Live2D animation into a single desktop application.

It is still evolving, and I hope that other developers can help turn this experiment into something more polished, efficient, and useful.

Feel free to explore the code, experiment with it, modify it, and build upon it.
